# Análisis de Datos de Aseguradora Médica

Este repositorio contiene un análisis exhaustivo de los datos de una aseguradora médica, utilizando fuentes de datos y herramientas de procesamiento de información para identificar patrones de siniestralidad, costes médicos, perfiles de asegurados y eficiencia en la prestación de servicios de salud.

---

## Descripción del proyecto
El objetivo principal de este proyecto es examinar la cartera de clientes, la siniestralidad y los costes asociados a los servicios médicos. A través del tratamiento y análisis de conjuntos de datos, se busca responder a preguntas clave sobre:
- **Perfil de asegurados:** distribución por edad, género, zona geográfica y tipo de póliza contratada.
- **Costes y siniestralidad:** análisis de los gastos médicos por especialidad, tratamientos más frecuentes y reclamaciones.
- **Uso de servicios:** frecuencia de visitas médicas, hospitalizaciones y eficiencia en la gestión de pólizas.

---

## Tecnologías, librerías y herramientas utilizadas
Este proyecto ha sido desarrollado utilizando un stack tecnológico enfocado en la ciencia de datos y el análisis estadístico:

- **Lenguaje de programación Python**

Lenguaje principal utilizado para la ingesta, transformación, análisis y modelado de los datos.

- **Librerías de análisis y procesamiento de datos**

Pandas: utilizado para la manipulación avanzada de estructuras de datos tabulares, filtrado, agregación y limpieza de los datasets de la aseguradora.

NumPy: empleado para operaciones numéricas eficientes y cálculos matriciales sobre los registros.

- **Librerías de visualización de datos**

Matplotlib: creación de gráficos estadísticos base (histogramas, gráficos de líneas y barras) para representar la evolución temporal de costes y siniestros.

Seaborn: generación de visualizaciones estadísticas avanzadas y mapas de calor (heatmaps) para correlaciones entre variables demográficas y de costes médicos.

- **Entornos de Desarrollo**

Jupyter Notebook / JupyterLab: entorno interactivo de desarrollo para la ejecución de bloques de código y la documentación visual del análisis paso a paso.

Visual Studio Code (VS Code): editor de código principal para la gestión de scripts y la estructuración general del proyecto.
